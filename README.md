# Smart To-Do App

A responsive and user-friendly To-Do application built using **HTML, CSS, and JavaScript**.

The app helps users manage daily tasks by adding, editing, deleting, completing, and filtering tasks. Tasks are stored in **LocalStorage**, so they remain available even after refreshing the page.

## Live Demo

🔗 https://ritumeena16.github.io/to-do-app/

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Filter tasks:
  - All
  - Pending
  - Completed
- Task counters:
  - Total Tasks
  - Pending
  - Completed
- Tasks persist using LocalStorage
- Data is restored after page refresh
- Responsive design for mobile and desktop
- Empty state when there are no tasks

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- DOM Manipulation

## How It Works

1. Enter a task in the input field.
2. Click **Add Task**.
3. Use the checkbox to mark a task as completed.
4. Click **Edit** to modify a task.
5. Click **Delete** to remove a task.
6. Use the filters to view All, Pending, or Completed tasks.
7. Tasks are automatically saved to LocalStorage.
